# Feliz Cumpleaños, Chan! 🎂

Página web especial de cumpleaños hecha a mano con HTML, CSS y JavaScript (estilo Pixel / Minecraft / Valorant).

## 🚀 Despliegue en Vercel

1. Inicia sesión en [Vercel](https://vercel.com).
2. Haz clic en **"Add New..."** -> **"Project"**.
3. Importa este repositorio de GitHub (`deimonshark-create/chan`).
4. Haz clic en **"Deploy"** (no requiere configuraciones adicionales de Build).

¡Y listo! Vercel te dará una URL pública gratuita con HTTPS.
